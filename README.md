# 💊 Medicine Reminder App

A simple web-based Medicine Reminder Application designed to help users organise their medication schedules and keep track of their daily medicines.

##  Features

- User-friendly interface
- Medicine reminder dashboard
- Organised medication schedule
- Simple navigation between pages

##  Technologies Used

- HTML5
- CSS3
- JavaScript

##  Project Structure

- `index.html` – Main application page
- `dashboard.html` – Medicine reminder dashboard
- `style.css` – Styling and layout
- `script.js` – Application functionality

##  How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the application.

##  Objective

To develop a simple and accessible web application that helps users organise their medication routines.
